# My Education App

**My Education App** is a simple, multi-screen React Native mobile application designed as a beginner-friendly learning platform. It allows users to browse programming courses, learn about the developer, and easily get in touch via an interactive contact form.

---

## 📱 Features

The application consists of four primary screens accessible through a intuitive bottom navigation bar:

### 1. Home Screen
* **Welcome Banner:** A clean, professional header welcoming users to the learning ecosystem.
* **App Introduction:** A short summary of how the platform empowers students with industry-ready coding skills.

### 2. Courses Screen
* **Course Catalog:** Displays available learning tracks using structured card layouts.
* **Details Action:** Interactive buttons for exploring individual course features.

### 3. About Screen
* **Developer Profile:** Showcases the creator.
* **Biography:** Highlights a strong academic pursuit and passion for cross-platform React Native development.
* **Social Network Connectivity:** Prominently links to professional networks including Instagram, GitHub, and LinkedIn.

### 4. Contact Screen
* **Interactive Contact Form:** Features input validation fields for User Name, Email, and Mobile Number.
* **Message Box:** A dedicated text area for custom inquiries and feedback.
* **Terms & Conditions:** A checkbox toggle ensuring compliance before submitting data.

---

## 🛠️ Tech Stack & Key Concepts Used

As a beginner project, the app focuses on foundational React Native building blocks:

* **React Native Core Components:** Extensive use of `View`, `Text`, `Image`, `TextInput`, `ScrollView`, and `TouchableOpacity`.
* **State Management (`useState`):** Utilized in the Contact form to handle real-time user inputs and checkbox selections.
* **Navigation:** Built using a simple tab navigation layout to switch cleanly between core views.
* **Styling & Layout:** Handled using flexbox properties for uniform alignment and responsive cross-device views.

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites
Make sure you have Node.js and the React Native development environment installed on your system.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/preetichaudhary-it/education-app-react-native.git
   ```
2. Navigate to the project directory:
   ```bash
   cd education-app-react-native
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running the App
* **For Expo users:**
  ```bash
  npx expo start
  ```
* **For React Native CLI users:**
  ```bash
  # For Android execution
  npx react-native run-android

  # For iOS execution
  npx react-native run-ios
  ```
